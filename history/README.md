# Sürüm arşivi

Bu klasör eski uygulama sürümlerinin kaynak anlık görüntülerini korur. Eski EXE veya taşınabilir ZIP paketleri yayımlanmaz. Güncel kaynak depo kökündedir.

| Sürüm | Kaynak | Başlıca değişiklik |
| --- | --- | --- |
| 1.0 | [v1.0](v1.0) | İlk WPF uygulaması, üç dinleme modu, pil |
| 1.1 | [v1.1](v1.1) | Normal modun geçici engellenmesi |
| 1.2 | [v1.2](v1.2) | Normal modun geri gelmesi |
| 1.3 | [v1.3](v1.3) | Sistem tepsisi |
| 1.4 | [v1.4](v1.4) | Windows ile başlatma, gizli açılış |
| 1.5 | [v1.5](v1.5) | Otomatik BLE yeniden bağlantısı |
| 1.5.1 | [v1.5.1](v1.5.1) | Bağlantı tanılama kayıtları |
| 1.6 | [Güncel kaynak](../src) | Önce ses bağlantısı, oyun modu |

[Ayrıntılı sürüm geçmişi](../docs/RELEASE-HISTORY.md) · [Yalnızca son sürümü indir](https://github.com/ardacob/air5-control/releases/latest)

Tarihsel kaynaklar eski hataları ve o zamanki davranışları da içerir. Özellikle 1.5/1.5.1, Windows ses çıkışı hazır olmadan BLE açabiliyordu. v1.6 kullanıcı tarafından doğrulanmış çözümü içerir.

İlk protokol/EQ araştırma araçları uygulama sürümü olarak dağıtılmıyor. APK, decompile edilmiş üçüncü taraf kod, firmware, cihaz kimlikleri ve kişisel test logları bu arşive dahil değildir.
