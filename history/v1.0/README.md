# Air5 Control v1.0

Ilk WPF surumu: ANC, Seffaflik, Normal, sol/sag/kutu pili, periyodik yenileme ve firmware gosterimi.

Tarihsel kaynak anlık görüntüsüdür; eski bir EXE veya indirme paketi dağıtılmaz.
Güncel uygulama için depo kökündeki README ve son sürüm bağlantısını kullan.
Bu klasördeki src ve Derle.ps1 o sürümün kaynaklarını, eski davranışlarıyla korur.
Özellikle 1.5 ve 1.5.1 ses kanalı hazır olmadan BLE açıyordu.
